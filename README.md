# DreamArts 2028 新卒エンジニア採用 コーディングテスト

## 開発環境

- Java 17

## 実行

### コンパイル

```bash
javac Main.java
```

### 実行

```bash
java Main < input.txt
```

## 入力例

```text
1, 2, 8.54
2, 3, 3.11
3, 1, 2.19
3, 4, 4
4, 1, 1.4
```

## アルゴリズム

1. 入力を読み込み、駅を頂点、路線を辺とする重み付き無向グラフを構築する
2. 全ての頂点を始点として深さ優先探索（DFS）を実行する
3. 訪問済み集合を用いて同一頂点への再訪問を防止する
4. 探索中の経路長を計算し、最長となる経路を記録する
5. 探索完了後、最長経路を出力する
